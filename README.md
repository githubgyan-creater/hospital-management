# Hospital Management System

A web-based Hospital Management System developed using PHP, MySQL,
HTML, CSS and Bootstrap.

## Features

- User Login and Registration
- Role-based Authentication
- Doctor Dashboard
- Patient Dashboard
- Doctor Profile Management
- Patient Profile Management
- Appointment Management
- Medical Reports
- Patient History
- Follow-up Management
- Secure Logout
- Responsive Bootstrap UI

## Technologies Used

- PHP
- MySQL
- HTML5
- CSS3
- Bootstrap
- XAMPP

## Project Structure

- Admin Panel
- Doctor Portal
- Patient Portal
- Authentication
- Database

## Local Setup

1. Install XAMPP.
2. Start Apache and MySQL.
3. Copy the project into:

   `C:\xampp\htdocs\`

4. Create the MySQL database using phpMyAdmin.
5. Import the database SQL file.
6. Update the database connection settings.
7. Open the project in the browser.
